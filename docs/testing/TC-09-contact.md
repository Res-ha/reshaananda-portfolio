# TC-09 — Contact

**Tujuan:** Memastikan validasi form kontak bekerja (positif & negatif), `mailto:` terbentuk benar, dan tidak ada data pengguna yang disimpan.

**Prasyarat:** `npm run dev`, buka `http://localhost:5173/contact`. Validasi ada di `ContactCard.tsx:25-26`: regex email `^[^\s@]+@[^\s@]+\.[^\s@]+$` dan pesan minimal **10 karakter** setelah `trim()`.

**Referensi:** PRD §3.11, §4.10; `src/components/sections/contact/ContactCard.tsx`
