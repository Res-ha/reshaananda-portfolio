# TC-03 — Light/Dark Mode

**Tujuan:** Memastikan toggle tema bekerja, preferensi tersimpan, tidak ada flash tema (FOUC), dan kedua mode terbaca jelas.

**Prasyarat:** `npm run dev`. Reset kondisi: hapus key `theme` dari localStorage. Default tema mengacu ke `index.html:15-25`.

**Referensi:** PRD §3.10; `index.html`, `src/lib/theme.tsx`
