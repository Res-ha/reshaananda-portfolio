# TC-07 — Certifications

**Tujuan:** Memastikan daftar sertifikasi lengkap, modal detail informatif, dan interaksi modal dapat diakses dari keyboard.

**Prasyarat:** `npm run dev`. Data acuan: **10 sertifikasi** di `src/data/credentials.ts`.

**Referensi:** PRD §3.8, §4.4; DESIGN §5, §8; `src/routes/certifications.tsx`

| ID         | Deskripsi                                        | Langkah Pengujian                                                                                                                                             | Hasil yang Diharapkan                                                                                                            | Jenis    |
| ---------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | -------- |
| TC-CRT-001 | Daftar menampilkan seluruh sertifikasi           | 1. Buka `/certifications`<br>2. Hitung jumlah card                                                                                                            | Seluruh **10 sertifikasi** tampil dalam grid card                                                                                | Positive |
| TC-CRT-002 | Klik card membuka modal detail                   | 1. Klik salah satu card sertifikasi                                                                                                                           | Modal (Dialog) terbuka menampilkan detail sertifikat tersebut                                                                    | Positive |
| TC-CRT-003 | Modal memuat gambar + metadata terstruktur       | 1. Buka modal sertifikasi<br>2. Amati isi modal                                                                                                               | Tampil gambar sertifikat dan metadata: nama, tipe (Course/Kursus), kategori, tanggal terbit, dan credential ID (PRD §3.8)        | Positive |
| TC-CRT-004 | Modal bisa ditutup dengan tiga cara              | 1. Buka modal, tutup via tombol **X**<br>2. Buka lagi, tutup dengan tombol **Escape**<br>3. Buka lagi, tutup dengan klik area overlay di luar modal           | Ketiga cara menutup modal dan kembali ke daftar; tidak ada scroll-lock yang tersisa                                              | Positive |
| TC-CRT-005 | Fokus keyboard terjaga saat modal dibuka/ditutup | 1. Tab ke card sertifikasi, tekan **Enter**<br>2. Periksa posisi fokus di dalam modal (tab berputar di dalam dialog)<br>3. Tutup modal, periksa fokus kembali | Fokus masuk ke dalam modal saat dibuka (focus trap) dan **kembali ke card** yang sama setelah ditutup (DESIGN §8)                | Edge     |
| TC-CRT-006 | Modal responsif di layar mobile                  | 1. Set viewport 375px<br>2. Buka modal sertifikasi                                                                                                            | Modal menyesuaikan lebar layar, gambar dan metadata tetap terbaca, bisa di-scroll tanpa elemen terpotong keluar layar (PRD §3.8) | Edge     |
| TC-CRT-007 | Metadata mengikuti bahasa aktif                  | 1. Set bahasa **EN**, buka modal, catat label tipe ("Course")<br>2. Toggle ke **ID**, buka modal lagi                                                         | Label tipe dan kategori berganti ("Kursus", "Analisis data") sesuai bahasa aktif                                                 | Edge     |
| TC-CRT-008 | Gambar sertifikat memiliki alt text              | 1. Inspeksi `<img>` sertifikat di dalam modal                                                                                                                 | Alt text deskriptif memuat nama sertifikasi, bukan nama file (DESIGN §8)                                                         | Edge     |
| TC-CRT-009 | Membuka modal tidak mengubah URL                 | 1. Catat URL saat di `/certifications`<br>2. Buka dan tutup modal                                                                                             | URL tetap `/certifications` — tidak ada hash/rute tambahan yang bisa memicu 404 saat di-share                                    | Edge     |
