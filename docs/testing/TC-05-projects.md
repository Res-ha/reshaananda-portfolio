# TC-05 — Projects

**Tujuan:** Memastikan katalog proyek lengkap, halaman detail informatif, dan slug tidak dikelola dengan aman.

**Prasyarat:** `npm run dev`. Data acuan: **6 proyek** di `src/data/projects.ts` (slug: `website-realtime-pemilu`, `website-portofolio-v2`, `live-sports-tracker`, `koperasi-berbasis-website`, `analisis-sentiment-topic-modeling`, `online-shop-codeigniter`).
