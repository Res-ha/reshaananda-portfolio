# TC-11 — Error Handling

**Tujuan:** Memastikan rute 404, halaman slug tak dikenal, dan Error Boundary menampilkan UI error yang jelas dan dapat pulih.

**Prasyarat:** `npm run dev`. Untuk TC-ERR-006 diperlukan simulasi error sementara (lihat langkahnya).

**Referensi:** PRD §3.12; `src/App.tsx` (ErrorBoundary, NotFound), `vercel.json`
