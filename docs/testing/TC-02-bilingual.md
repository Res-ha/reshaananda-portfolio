# TC-02 — Bilingual EN/ID

**Tujuan:** Memastikan toggle bahasa mengganti seluruh teks UI dan konten, preferensi tersimpan, dan atribut `<html lang>` sinkron.

**Prasyarat:** `npm run dev`. Reset kondisi: hapus key `lang` dari localStorage sebelum kasus default.

**Referensi:** PRD §3.3, §4.7; `src/lib/LanguageProvider.tsx` (key `lang`), `src/lib/i18n.ts`
