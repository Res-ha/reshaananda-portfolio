# TC-14 — Performance & Reliability

**Tujuan:** Memastikan target performa (Lighthouse ≥ 90, FCP < 1,5s), tidak ada error konsol, tidak ada link rusak, dan build produksi sehat.

**Prasyarat:** Untuk metrik: `npm run build && npm run preview`, throttle jaringan 4G via DevTools. Untuk TC-PER-009: Node.js LTS + npm.

**Referensi:** PRD §2 (Performance, Reliability, Privacy), §7.4; DESIGN §10
