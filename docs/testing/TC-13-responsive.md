# TC-13 — Responsive Layout

**Tujuan:** Memastikan layout stabil di tiga breakpoint target (375px, 768px, 1280px+) tanpa overflow dan tetap nyaman disentuh.

**Prasyarat:** `npm run dev`. Gunakan responsive mode DevTools atau resize browser.

**Referensi:** DESIGN §7; PRD §7.2 (responsif)
