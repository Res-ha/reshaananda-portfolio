# TC-04 — Home / Landing Page

**Tujuan:** Memastikan homepage menyajikan alur cerita lengkap (hero → about → capabilities → experience → projects → contact) dengan data yang benar.

**Prasyarat:** `npm run dev`, buka `http://localhost:5173/`.

**Referensi:** PRD §3.1, §4.1; DESIGN §5 (Hero, Capabilities, Experience, Featured projects)
