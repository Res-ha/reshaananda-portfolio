# TC-12 — Accessibility (A11Y)

**Tujuan:** Memastikan aksesibilitas sesuai WCAG AA: navigasi keyboard penuh, kontras memadai, semantik ARIA, dan dukungan `prefers-reduced-motion`.

**Prasyarat:** `npm run dev`. Alat bantu: DevTools Lighthouse (Accessibility audit), tab keyboard, ekstensi kontras opsional.

**Referensi:** PRD §2 Accessibility; DESIGN §8; `src/App.tsx` (skip link), `src/components/layout/SiteNav.tsx`

Tekan **Enter**                                                                                                      | Link "Skip to content" muncul di kiri atas, lalu fokus melompat ke `#main-content` (App.tsx:90)                                            | Positive |
