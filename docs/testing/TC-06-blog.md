# TC-06 — Blog

**Tujuan:** Memastikan daftar dan detail tulisan berfungsi, konten bilingual tampil benar, dan slug tak dikenal ditangani tanpa crash.

**Prasyarat:** `npm run dev`. Data acuan: **4 tulisan** di `src/data/posts.ts` (slug: `kenapa-saya-masih-pakai-php`, `catatan-troubleshooting-jaringan`, `belajar-flutter-pelan-pelan`, `menulis-dokumentasi-yang-dibaca`).

**Referensi:** PRD §3.6, §4.5; `src/routes/blog.index.tsx`, `src/routes/blog.$slug.tsx`
