# /poteto-help

**Usage:**

```
/poteto-help
/poteto-help <context about your task>
```

**Examples:**

```
/poteto-help
/poteto-help I have a flaky test that fails 1 in 20 runs
/poteto-help I need to design a new API contract
/poteto-help My PR has 200 comments, help me review
```

**What it does:**

- Lists all pstack skills and agents
- Recommends the right skill for your context
- Shows the 24 principles index
- Quick start guide
